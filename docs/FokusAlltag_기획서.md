## 0. 한 줄 정의

> **"오늘 REWE에서 있었던 일"을 매일 독일어로 말하고 → AI가 B1/B2/원어민 표현으로 교정하고 → 외울 3문장을 Fokus DE 문장으로 쌓는 앱.**
> 시험 준비 앱이 아니라, 내 생활을 교재로 만드는 앱.

단어·문장 **복습**은 Fokus DE / Karten이 이미 잘한다. 이 앱은 그 앞단 — **문장을 만들어 내는 일**과 **6개월 진도 관리**만 맡는다.

## 0-1. Fokus 패밀리 안에서의 역할

세 앱이 **입력 → 저장 → 암기 → 산출**을 한 바퀴 돈다. 같은 일을 두 앱이 하지 않는다.

| 앱 | 맡는 일 | 안 하는 일 |
|---|---|---|
| **Fokus DE** | 독일어 콘텐츠 창고 (단어·문장·태그), 빈칸·받아쓰기·4지선다 | 자유 말하기·AI 교정 |
| **Karten** | 플립 암기 (FSRS) | 문장 만들기 |
| **Alltag (신규)** | **산출** — 말하기·쓰기, AI 교정, 6개월 진도 | 암기 복습 (Karten/DE로 보냄) |

```
Alltag 기록 ─(교정)→ 외울 3문장 ─저장→ DE user_sentences ─덱→ Karten 암기
   ↑                                   │
   └──── 오늘의 미션 단어·예문 ◄────────┘  (DE에서 읽어 옴)
```

### 연결 지점 7개

**Alltag → DE / Karten (보내기)**
1. **외울 3문장 → `user_sentences`** + notebook `Alltag` → Karten에 덱으로 자동 등장
2. **교정에서 처음 나온 단어 → `custom_words`** — 예: 교정 결과에 `geeignet`이 새로 나오면 "내 단어에 추가" 버튼. DE에 이미 있으면 버튼 대신 ✓ 표시
3. **발음 파일 공유** — 저장한 문장의 원어민 발음을 `card_meta`(열쇠 `sentence:<id>`)에 한 번 만들면 DE·Karten에서 같은 파일로 재생. 세 앱이 같은 `api/tts.js`
4. **태그는 기존 태그에 맞춤** — AI가 주제 태그를 제안하면 `tagSimilarity.js`(DE에서 복사)로 기존 태그와 비교해 `Parkplatz`/`parken` 같은 중복 태그를 안 만든다. 태그 병합을 다시 할 일이 안 생기게

**DE → Alltag (가져오기)**
5. **오늘의 미션 단어** — 기록 화면 위에 "오늘 이 단어 2개를 넣어 말해 보세요". DE에서 최근 배운 단어·자주 틀린 단어를 뽑는다 → 외운 단어가 실제 말하기로 넘어감
6. **문법별 내 예문** — 문법 8개 화면에서 `weil`을 누르면 DE에 이미 있는 `weil` 문장을 보여 줌 (새 예문 만들기 전 참고)

**앱 사이 이동**
7. **바로가기 링크** — 교정 후 "Karten에서 오늘 3문장 외우기" / 진도 화면에서 "DE에서 B2-Programm 문장 보기(태그 필터 적용)". 새로 만들지 않고 **가기** (feature placement 규칙 3)

### 반복 화면의 역할 정리
원래 안의 "3문장 소리 내서 반복"은 **암기**와 **말하기** 두 가지가 섞여 있었다.
- 암기(뜻↔문장) → **Karten 덱**으로 보냄. Alltag에 복습 화면을 또 만들지 않음
- 말하기(뜻만 보고 독일어로 **꺼내기** → 발음 비교) → **Alltag에만** 둠. DE·Karten 어디에도 없는 기능

## 0-2. 학습 원리 — "수행"이 아니라 "학습" (2026-09-23 추가)

근거: 뇌과학 기반 학습법 5원리(인출 · 간격 · 교차 · 자기 설명 · 연결)와 "바람직한 어려움".
**다시 읽기·따라 하기처럼 편한 것은 수행(performance)이고, 스스로 꺼내는 것이 학습(learning)이다.**
이 앱의 모든 화면은 이 기준으로 설계한다.

| 원리 | 이 앱에서 | 들어가는 곳 |
|---|---|---|
| **인출 연습** | 외울 3문장은 따라 읽지 않는다. **한국어 뜻만 보고 독일어로 말한 뒤** 정답을 연다 | 🔴 인출 화면 (CP3) |
| **간격 두기** | 뜻↔문장 복습은 Karten FSRS가 맡는다(이미 있음). Alltag는 **1·3·7·14일 전 문장을 오늘 상황으로 바꿔 말하는** 되살리기 1분 — 알아보기가 아니라 다시 만들기 | 기록 화면 워밍업 (CP3) |
| **교차 연습** | 3개월차부터 **지난 형식을 섞는다**. 미션 문법은 "이번 주 문법"이 아니라 **배운 문법 중 무작위 1~2개** | 템플릿 규칙 (CP1) · 미션 (CP4) |
| **자기 설명** | 교정은 한 번에 보여 주지 않는다. **틀린 위치만 표시 → 내가 고침 → 정답 공개 → 핵심 문법 하나를 내 말로 설명** → AI가 확인 | ③ 교정 결과 (CP2) |
| **연결 (덩어리)** | 3단계 확장이 곧 덩어리 만들기. 저장할 때 **DE의 같은 문법·같은 상황 문장을 옆에 보여 줘** 이미 아는 것에 붙인다 | 교정 5단계 · 진도 문법 (CP2·CP4) |

**원칙 세 가지**
1. **단계를 늘리지 않고 바꾼다.** 하루 20분(10분 모드) 예산은 그대로다. 반복 → 인출, 한 번에 공개 → 단계 공개로 *교체*한다.
2. **정답은 시도한 뒤에만 연다.** 모든 공개 버튼 앞에 "먼저 해 보기"가 있다. 단, 건너뛰기는 언제나 가능 — 지친 날 앱이 벽이 되면 연속이 끊긴다.
3. **막힘을 실패로 표시하지 않는다.** 인출에 실패하면 빨간 ✗ 대신 "막히는 순간이 기억이 만들어지는 순간"류의 문구. 성공률은 기록하되 벌점처럼 보이지 않게.

## 2. 화면 구성 (탭 4개)

### ① 오늘 (Heute) — 기본 화면
- 상단: `3개월차 · 2단계 "B2 문장 구조"` + 연속 일수
- 오늘 루틴 체크리스트 (계획서의 하루 구성 그대로)
  - 🟢 듣기 5분 → 타이머 + 들은 내용 한 줄 요약(독일어)
  - 🟡 말하기 10분 → **기록 화면으로 이동** (첫 1분은 되살리기 워밍업)
  - 🔵 AI 교정 5분 → 기록 후 자동 (스스로 고치기 → 공개 → 설명)
  - 🔴 3문장 인출 5~10분 → 인출 화면 (한국어 보고 독일어로 말하기)
- **"오늘은 10분만" 버튼**: 말하기 1개 + 3문장 인출만 남김. 이것도 연속 일수에 포함 (계획: "끊기지 않는 것이 중요")
- 일요일: "휴식 또는 복습" — 쉬어도 연속이 안 끊김

### ② 기록 (Eintrag) — 핵심
입력 방식 3가지:
- 🎤 **말하기** — 브라우저 음성 인식(de-DE)으로 받아쓰기 → 텍스트 수정 가능
- ⌨️ **타이핑**
- 🇰🇷 **한국어로** — 지친 날. AI가 독일어로 만들어 줌 (표시: "오늘은 한국어 입력")
- **의도 먼저 쓰기** (2026-09-30) — 독일어 모드에서 칸마다 첫 줄에 하려는 말을 한국어로, 다음 줄에 독일어로. 한글 줄은 교정 대상이 아니라 의도로 AI 에 넘긴다(`correct.js markIntent`). 독일어가 의도와 뜻이 다르면 type `Bedeutung` 으로 고친다

**되살리기 워밍업 (1분, 간격+인출)** — 기록 칸 위에 카드 하나:
- 1·3·7·14일 전에 저장한 외울 문장 중 하나의 **한국어 뜻**을 보여 준다
- 독일어로 말해 본 뒤 정답을 연다 → 이어서 "오늘 상황으로 바꿔 한 문장" (예: Parkplatz 문장을 오늘 계단 이야기로)
- 하루 1개. 건너뛸 수 있다. 결과(성공/막힘)는 `alltag_entries.parts.revive` 에 남긴다

**오늘의 미션 (교차)** — "이 단어 2개 + 이 문법 1개를 넣어 말해 보세요". 문법은 지금까지 배운 것 중 무작위, 단어는 DE에서.

**단계별 템플릿**이 입력 칸 모양을 바꾼다:

| 개월 | 템플릿 | 입력 칸 |
|---|---|---|
| 1~2 | 3단계 확장 | Level 1 → Level 2 (weil/obwohl…) → Level 3 (구체화) |
| 3~4 | "왜?" 답하기 | 질문 1개 (예: Warum bist du später gekommen?) → B1 답 → B2 답 → B2+ 답 |
| 5 | 문제 해결 4칸 | Was ist passiert? / Warum? / Folge / Verbesserung |
| 6 | 요일 루틴 | 월 업무설명 · 화 뉴스요약 · 수 의견 · 목 이메일(150~200단어) · 금 문제설명 · 토 자유말하기 5~10분 · 일 휴식 |

템플릿은 자동으로 정해지지만 수동으로 바꿀 수 있다.
3단계 확장의 **Level 2·3 은 [건너뛰기]** 가능 (2026-10-08) — 건너뛴 칸은 글이 남아 있어도 교정에 보내지 않고(`parts.skip`), [다시 쓰기] 하면 쓰던 글이 돌아온다. Level 2 를 건너뛰면 Level 3 의 "앞 칸 가져오기"는 Level 1 에서.

**교차 규칙** (1~2개월은 기초라 섞지 않는다):
- 3~4개월: 주 2회(월·목) 지난 형식(3단계 확장)
- 5개월: 주 2회(화·금) 지난 형식 중 무작위(3단계 확장 / "왜?")
- 6개월: 요일 루틴 자체가 교차
- 섞는 날은 오늘 화면 형식 카드에 "섞는 날" 표시 — 이유를 알아야 이상하게 느끼지 않는다

### ③ 교정 결과 (기록 저장 후 표시) — 단계별 공개
계획서의 5단계를 **한 번에 보여 주지 않고** 시도 → 공개 순서로 연다 (0-2절 자기 설명·인출):
1. **스스로 고치기** — 내 글에 틀린 **위치만** 밑줄 + 유형 힌트(관사 · 동사 위치 …). 정답은 없다. 내가 고쳐 쓴다 [건너뛰기]
2. **B1 교정 공개** — 내 수정과 나란히. 맞게 고친 곳 ✓ (고친 수를 기록 → 진도의 "스스로 고친 비율")
3. **B2 → 원어민** — B2를 열기 전 "B2로 올려 보기" 한 줄 시도(선택) → 공개
4. **자기 설명** — 핵심 문법 하나(8개 중)를 골라 "왜 이렇게 되나"를 한 줄로(한국어 OK) → AI가 맞음/보충
5. **오늘 외울 문장 3개** — 수정 가능 + 옆에 **DE의 같은 문법·같은 상황 문장 1~2개** (연결) → [Fokus DE에 저장]

AI 호출은 **교정 1회**(전부 받아 두고 화면에서만 나눠 연다 — 비용 그대로) + **자기 설명 확인 1회**(짧음, Haiku 4.5).

저장 시 `user_sentences`에:
- german / korean
- tags: `B2-Programm`, `M3`(개월), 문법 태그(`weil`, `Passiv`…), 주제 태그(`Lieferung`, `Parkplatz`…)
- notebook: `Alltag` (Karten에서 덱으로 바로 보임 — CP0에서 컬럼 확인)

### ④ 진도 (Fortschritt)
- **6개월 로드맵** 표 — 현재 월 강조, 월별 기록 수
- **B2 문법 8개** — 각 문법이 들어간 **내 문장 개수** (문법을 "아는 것"이 아니라 "쓴 것"으로 측정)

- **자주 틀리는 것** — AI가 매번 돌려주는 오류 유형 누적 Top 5 (예: 관사, 동사 위치, 전치사). 유형을 누르면 그 유형만 **오답 노트**로 연습하고, 아래 [DE에서 같은 문법 더 연습] → DE Dojo 📐 문법 (0-5절)

### 인출 화면 (오늘 → 🔴에서 진입) — 따라 말하기가 아니라 꺼내기

## 3. AI 교정 — DE의 `anthropic` Edge Function 재사용

- Fokus DE `supabase/functions/anthropic` 는 요청 본문을 그대로 Anthropic API에 넘기는 통로다. 키(`ANTHROPIC_API_KEY`)는 이미 Supabase 비밀값에 있다 → **Alltag는 model만 바꿔 같은 통로를 쓴다**
- 호출은 `src/lib/ai.js` 한 곳에서만. DE `callAnthropic` 과 같은 모양
- **하루 호출 상한** 20회
- 응답은 JSON 고정:

```json
{
  "b1": { "text": "...", "fixes": [{ "from": "...", "to": "...", "type": "Artikel", "hint": "명사의 성을 다시 봐요", "why": "Parkplatz는 남성 → keinen" }] },
  "b2": "...",
  "native": "...",
  "grammar": [{ "key": "weil", "note": "종속절에서 동사는 끝으로" }],
  "keep": [{ "de": "...", "ko": "...", "grammar": "weil", "topic": "Parkplatz" }],
  "errorTypes": ["Artikel", "Verbstellung"]
}
```

- 1단계(스스로 고치기)에는 `from`·`type`·`hint`만 보여 준다. `to`·`why`는 2단계에서 공개 — 프롬프트에 "hint에는 정답 단어를 쓰지 말 것" 명시
- 자기 설명 확인 호출: `{ grammar, sentence, myExplanation }` → `{ ok: bool, add: "보충 한 줄" }`
- 프롬프트 맥락: REWE 배송 업무, 현재 개월/템플릿, 목표 수준. 한국어 입력이면 "독일어 문장 만들기 + 사용자가 만든 게 아님" 표시
- 공급자·모델은 3-1절

### 3-1. 모델과 비용 상한

**기본 모델: Claude Sonnet 5** (`claude-sonnet-5`, 입력 $2 / 출력 $10 per 1M 토큰)
- 이유: 이 앱에서 교정 품질이 곧 학습 품질. "원어민이 실제로 말할 법한 표현"과 틀린 이유 설명은 모델 차이가 크다. 잘못 교정된 문장을 Karten에서 외우면 손해가 누적됨
- 1회 추정: 입력 ~2,000 토큰(지시문+내 문장) + 출력 ~1,000 토큰(JSON, 독·한) ≈ **$0.014 (약 20원)**
- 하루 2회 × 30일 ≈ **월 $0.85**. 6개월차 이메일(200단어)·월말 점검을 더해도 월 $1.5 안쪽

**절약 모델: Claude Haiku 4.5** (`claude-haiku-4-5-20251001`, $1 / $5) — 1회 약 $0.007

**상한 장치 (앱이 호출 전에 판정 + Console 한도가 최후 방어선)**
| 조건 | 동작 |
|---|---|
| 하루 20회 | 그날 교정 중지 (실수 반복 호출 방지) |
| 월 $2.40 (80%) 도달 | 자동으로 Haiku 4.5로 전환, 화면에 "절약 모드" 표시 |
| 월 $3 도달 | AI 교정 중지 → **복사-붙여넣기 모드**: 프롬프트를 복사해 Claude 앱에 붙이고 답을 다시 붙이면 같은 화면으로 정리 |

- 비용은 응답의 실제 토큰 수로 계산해 **DE의 `ai_usage_log`에 기록** (provider `anthropic`, kind `alltag-correct` 등 `alltag-` 접두사). 덕분에 DE 관리자 "📊 AI 사용량" 탭에 Alltag 비용이 같이 보인다 — 새 테이블 없음
- 상한 판정 = 이번 달 `ai_usage_log` 중 kind가 `alltag-`로 시작하는 행의 cost_usd 합
- ⚠ DE `aiUsage.js` 의 `MODEL_PRICING` 에 Sonnet 5 단가가 없으면 DE 화면의 비용 표시가 0으로 나온다 — CP2에서 DE 쪽에 한 줄 추가
- 이중 안전장치: Claude Console에서도 월 사용 한도를 $5로 설정 (Edge Function은 상한 없이 그대로 넘기므로)
- 설정값: `VITE_ALLTAG_AI_MODEL`(기본 claude-sonnet-5), `VITE_ALLTAG_MONTHLY_CAP_USD`(기본 3) — 키가 아니라서 VITE_ 여도 안전
- 요금 출처: https://platform.claude.com/docs/en/about-claude/pricing (2026-09-23 확인)

| 1~2 | 동료 | 짧은 3~4턴, 3단계 확장을 대화로 |
| 3~4 | Disponent | "왜?"를 계속 파고드는 대화 |
| 5 | 팀장 | 문제 보고 → 원인 → 해결책 제안 |
| 6 | 요일마다 다름 | 고객 · 동료 · 팀장 (목요일 이메일은 쓰기 그대로) |

**맞는 점:** 6개월 목표(문제 상황을 3~5분 설명)가 원래 대화다 · "왜?" 형식은 질문하는 상대가 있어야 성립 · 즉석 발화 = 인출 + 자연스러운 교차 + 바람직한 어려움.

**지켜야 할 조건 (검토 때 기준):**
1. 장면은 반드시 **오늘 기록한 일에서 출발** — 가상의 "호텔 체크인"류가 되면 "내 하루가 교재" 원칙을 잃는다
2. 대화 중에는 교정하지 않는다 — 끝난 뒤 내 발화만 모아 기존 단계별 공개(0-2절)로
3. 비용 — 턴마다 앞 내용을 다시 보내므로 Sonnet만 쓰면 1회 약 $0.08~0.1(매일이면 $3 상한 초과). **상대역 Haiku 4.5 + 교정 Sonnet 5**로 나누면 1회 약 $0.03, 월 $1 안팎
4. 게임 요소는 점수·레벨이 아니라 **장면 목표 달성**("재배송 시간 합의하기")으로 끝나고, 막히면 첫 단어 힌트

**적용하게 되면 바뀌는 것:** CP1 기록 화면에 대화 모드 추가(음성 입력 + 상대 대사 TTS), CP2 교정 입력이 "글 한 편" → "대화 기록에서 내 발화"로. `alltag_entries.parts` 에 턴 배열을 담으면 테이블 변경 없음. 월말 말하기 점검(CP5)도 같은 틀의 3~5분 장면으로.
